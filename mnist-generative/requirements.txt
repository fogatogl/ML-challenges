# IMPORTANT: this deliberately does NOT pin torch / torchvision.
# The Onyxia "service-pytorch" image ships a torch build matched to its
# CUDA driver. Re-installing torch via pip can silently swap in a CPU-only
# or CUDA-mismatched wheel and break GPU access. Verify what's already
# there with `python scripts/check_env.py` before adding anything torch-related.
# If torchvision is missing (rare), add it manually matching your torch's
# CUDA tag, e.g.: pip install torchvision --index-url https://download.pytorch.org/whl/cu121
